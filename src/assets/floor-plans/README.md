# Brown-Kopel floor plans

These two map images are the official floor-plan assets displayed by the Brown-Kopel reservation site:

- `BKESAC-basement.png`: <https://brownkopel.eng.auburn.edu/Sites/site_6/files/img/BKESAC-basement.png>
- `BKESAC-second.png`: <https://brownkopel.eng.auburn.edu/Sites/site_6/files/img/BKESAC-second.png>

They are stored locally so the reservation prototype does not depend on the production reservation server for its primary wayfinding surface.
